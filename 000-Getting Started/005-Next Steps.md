Next Steps
================================

Now you have installed HaxeUI, installed a backend and compiled a "Hello World" application there are a few other resources that will help you one your way:

* [component-explorer](https://www.haxeui.org/explorer) - Browse HaxeUI components
* [playground](https://www.haxeui.org/builder) - Write and test HaxeUI layouts in your browser
* [component-examples](https://github.com/haxeui/component-examples) - Various componet examples
* [haxeui-api](https://www.haxeui.org/api/haxe/ui/) - The HaxeUI api docs
* [haxeui-guides](../001-Guides/index.md) - Set of guides to working with HaxeUI and backends
